## 2026-10-19

### Futures V3 — Get Invitee Info

* Added `GET /fapi/v3/referral/inviteeInfo` (USER_DATA, weight 1): check whether a wallet address joined through the caller's referral.
* Parameters: `address` (EVM or Solana wallet address).
* Response when `isInvitee: true`: `walletAddress`, `dateJoined`, `feePaid`, `yourRewards`, `expiredStatus`.
* Response when `isInvitee: false`: `walletAddress` only.
* Referral relationships are valid for 365 days. An expired relationship still returns `isInvitee: true` with `expiredStatus: true`.
