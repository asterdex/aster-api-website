## 2026-10-08

### Futures V3 & Testnet — Builder 查询接口

* 新增 `GET /fapi/v3/builder/userAccounts` — 查询 Builder 管理用户的账户信息。
* 新增 `GET /fapi/v3/builder/userOpenOrders` — 查询 Builder 管理用户的当前挂单。
* 新增 `GET /fapi/v3/builder/userBalances` — 查询 Builder 管理用户的余额。
* 新增 `GET /fapi/v3/builder/userPositionRisk` — 查询 Builder 管理用户的持仓风险。
* 新增 `GET /fapi/v3/builder/userCommissionRates` — 查询 Builder 管理用户的手续费率。
* 新增 `GET /fapi/v3/builder/userAllOrders` — 查询 Builder 管理用户的全部订单。
* 修正 `GET /fapi/v3/builder/userTrades`：`fee` 现正确标注为负数（Maker 返佣）；可查询时间窗口延长至 90 天；新增 `userAddresses` 参数；响应中新增 `errors[]` 字段。

### Futures V3 & Testnet — 公共接口

* 新增 `GET /fapi/v3/common/asset/all-asset-logo` — 公开接口，获取全部资产 Logo 地址。响应字段：`assetCode`（STRING）、`logoUrl`（STRING）。

### Futures V3 & Testnet — 资产兑换

* 新增 `POST /fapi/v3/assetExchange` — 在多资产模式下进行资产兑换（TRADE 权限，权重：1）。

### Futures V3 & Testnet — 剩余可开仓名义价值

* 新增 `GET /fapi/v3/remainingOpenableNotionalValue` — 查询指定交易对和杠杆倍数下的剩余可开仓名义价值（权重：50）。

### Futures V3 & Testnet — 文档修正

* `GET /fapi/v3/exchangeInfo`：新增 `futuresType` 字段；`OrderType` 重命名为 `orderTypes`；`timeInForce` 数组中移除 `FOK`。
* 下单响应：新增 `pegPriceType` 和 `stpMode` 字段；权重修正为 0。
* 下单：补充 `STOP_MARKET`、`TAKE_PROFIT_MARKET`、`TRAILING_STOP_MARKET` 订单类型的 `timeInForce` 说明。
* 修改订单：新增 `side` 参数；`quantity` 和 `price` 标注为必填（YES）。
* `POST /fapi/v3/wallet/transfer` 权重修正：5 → 50。
* `GET /fapi/v3/allOrders`：`symbol` 改为可选；不传时返回所有交易对的订单。
* `GET /fapi/v3/account`（accountWithJoinMargin）：持仓风险部分新增 `notional` 和 `isolatedWallet` 字段；补充关于 `GET /fapi/v3/account` 接口的说明。
* `POST /fapi/v3/positionMargin`：新增 `clientTranId` 参数；响应新增 `deltaType` 和 `clientTranId` 字段。
* `GET /fapi/v3/positionRisk`：三种持仓方向（BOTH/LONG/SHORT）的响应示例均新增 `notional` 和 `isolatedWallet` 字段。
* `GET /fapi/v3/userTrades`：新增 `orderId` 参数。
* `GET /fapi/v3/income`：`incomeType` 枚举值扩展，新增 `REFERRAL_KICKBACK`、`COMMISSION_REBATE`、`MARKET_MAKER_REBATE`、`API_REBATE`、`CONTEST_REWARD`、`CROSS_COLLATERAL_TRANSFER`、`INTERNAL_TRANSFER`、`AUTO_EXCHANGE`。
* `GET /fapi/v3/leverageBracket` 重命名为 `GET /fapi/v3/leverageBrackets`（旧路径已弃用）。
* 查询历史成交：移除 `startTime` 与 `endTime` 之间必须小于 1 小时的限制。
* 基础信息：新增 `TRANSFER` 和 `WITHDRAW` 安全类型；nonce 有效窗口从 10 秒延长至 60 秒；移除 `FOK`（Fill or Kill）有效方法；速率限制时间间隔新增 `SECOND`、`TEN_SECONDS`、`DAY`。
* 错误码 `-2011` 描述修正为"订单不存在。"
* 各接口 `timeInForce` 参数现链接至枚举定义章节。
