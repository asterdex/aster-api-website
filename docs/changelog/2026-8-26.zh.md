## 2026-08-26

### Futures V3 & Testnet — 子账户划转

* `POST /fapi/v3/subAccountTransfer` 的 `user` 和 `signer` 参数现均为可选，传其中一个即可标识签名账户。
* 新增 `signer` 参数：经授权的 Agent 钱包现可代表 `user` 对子账户划转进行签名。
* `参数取值` 表新增 `signer` 列，明确各划转场景下的签名账户。
* 更新「签名说明」和「注意事项」，以反映 Agent 签名支持。

### Futures V3 & Testnet — 批量修改订单

* 新增 `PUT /fapi/v3/batchOrders` ——单次请求最多批量修改 5 笔挂单（做市商白名单账户最多 10 笔）。
* 每笔订单需传 `symbol`、`quantity`、`price`，并须提供 `orderId` 或 `origClientOrderId` 之一。
* 批量处理非原子性：每笔订单修改独立成功或失败。

### Aster-Chain — 充值文档

* 新增 Aster-Chain 充值章节，涵盖 EVM、Solana 和 SUI 充值方式。
* EVM：`depositFor` 合约方法，含 ETH、BSC、Arbitrum 主网合约地址。
* Solana：`depositSol` 和 `depositToken` 程序方法，含主网 Program 地址。
* SUI：仅支持现货账户，通过专属充值地址直接转账（`GET /aster-chain/v3/spot/user-deposit-address`）。

### Aster-Chain — 合约 & 现货提现/划转接口

* 新增 Aster-Chain 合约提现与划转接口：`POST /aster-chain/v3/perp/user-withdraw`、`POST /aster-chain/v3/perp/user-solana-withdraw`、`GET /aster-chain/v3/perp/user-withdraw-info`、`GET /aster-chain/v3/perp/deposit-withdraw-history`、`POST /aster-chain/v3/perp/wallet/transfer`。
* 新增 Aster-Chain 现货提现与划转接口：`POST /aster-chain/v3/spot/user-withdraw`（含 `signatureChainId` 参数）、`POST /aster-chain/v3/spot/user-solana-withdraw`、`POST /aster-chain/v3/spot/wallet/transfer`。
* 新增 Aster-Chain 提现接口：`GET /aster-chain/v3/withdraw/estimateFee`。
