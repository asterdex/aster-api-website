## 2026-10-08

### Futures V3 & Testnet — Builder Query Endpoints

* Added `GET /fapi/v3/builder/userAccounts` — query account info for all users managed by a Builder.
* Added `GET /fapi/v3/builder/userOpenOrders` — query open orders for Builder-managed users.
* Added `GET /fapi/v3/builder/userBalances` — query balances for Builder-managed users.
* Added `GET /fapi/v3/builder/userPositionRisk` — query position risk for Builder-managed users.
* Added `GET /fapi/v3/builder/userCommissionRates` — query commission rates for Builder-managed users.
* Added `GET /fapi/v3/builder/userAllOrders` — query all orders for Builder-managed users.
* Fixed `GET /fapi/v3/builder/userTrades`: `fee` is now correctly documented as negative (maker rebate); lookback window extended to 90 days; added `userAddresses` parameter; added `errors[]` field in response.

### Futures V3 & Testnet — Common Endpoints

* Added `GET /fapi/v3/common/asset/all-asset-logo` — public endpoint to retrieve all asset logo URLs. Response: `assetCode` (STRING), `logoUrl` (STRING).

### Futures V3 & Testnet — Asset Exchange

* Added `POST /fapi/v3/assetExchange` — exchange assets in Multi-Assets Mode (TRADE security, weight: 1).

### Futures V3 & Testnet — Remaining Openable Notional Value

* Added `GET /fapi/v3/remainingOpenableNotionalValue` — query the remaining openable notional value for a symbol and leverage combination (weight: 50).

### Futures V3 & Testnet — Documentation Corrections

* `GET /fapi/v3/exchangeInfo`: added `futuresType` field; renamed `OrderType` → `orderTypes`; removed `FOK` from `timeInForce` array.
* New Order response: added `pegPriceType` and `stpMode` fields; weight corrected to 0.
* New Order: added notes on `timeInForce` behavior for `STOP_MARKET`, `TAKE_PROFIT_MARKET`, and `TRAILING_STOP_MARKET` order types.
* Modify Order: added `side` parameter; `quantity` and `price` are now marked as required (YES).
* `POST /fapi/v3/wallet/transfer` weight corrected: 5 → 50.
* `GET /fapi/v3/allOrders`: `symbol` is now optional; omitting it returns orders across all symbols.
* `GET /fapi/v3/account` (accountWithJoinMargin): added `notional` and `isolatedWallet` fields to position risk section; added note about `GET /fapi/v3/account` endpoint.
* `POST /fapi/v3/positionMargin`: added `clientTranId` parameter; response now includes `deltaType` and `clientTranId` fields.
* `GET /fapi/v3/positionRisk`: added `notional` and `isolatedWallet` fields to all position side examples.
* `GET /fapi/v3/userTrades`: added `orderId` parameter.
* `GET /fapi/v3/income`: expanded `incomeType` enum to include `REFERRAL_KICKBACK`, `COMMISSION_REBATE`, `MARKET_MAKER_REBATE`, `API_REBATE`, `CONTEST_REWARD`, `CROSS_COLLATERAL_TRANSFER`, `INTERNAL_TRANSFER`, `AUTO_EXCHANGE`.
* `GET /fapi/v3/leverageBracket` renamed to `GET /fapi/v3/leverageBrackets` (old path deprecated).
* Old Trades Lookup: removed 1-hour time-range restriction between `startTime` and `endTime`.
* General Info: added `TRANSFER` and `WITHDRAW` security types; nonce validity window extended from 10 → 60 seconds; removed `FOK` (Fill or Kill) from supported `timeInForce` values; added `SECOND`, `TEN_SECONDS`, `DAY` to rate limit interval definitions.
