## 2026-10-27

### Futures V3 — 查询Builder用户佣金

* 新增 `GET /fapi/v3/builder/userCommissions`（USER_DATA，权重 5）：分页查询调用者 Builder 代码下用户成交产生的 Builder 手续费。
* 参数：`userAddresses`（最多 50 个，逗号分隔）、`startTime`、`endTime`、`page`（默认 1）、`limit`（默认 50；最大 1000）、`nonce`、`signer`、`signature`。
* 查询的成交范围与 `GET /fapi/v3/builder/userTrades` 相同，但仅返回手续费相关字段（`tradeId`、`insertTime`、`orderId`、`symbol`、`feeAsset`、`marginAsset`、`builderFee`、`userAddress`）。
* 不受用户隐私模式限制——已开启隐私模式的用户的成交也会返回。
* 时间窗口：默认最近 7 天；`startTime` 不能早于 90 天前。

## 2026-10-22

### Futures V3 & Testnet — 分页获取账户损益资金流水

* 新增 `GET /fapi/v3/incomePage`（USER_DATA，权重 30）：分页返回账户损益资金流水，支持 `symbol`、`incomeType`、`startTime`、`endTime`、`page`（默认 1）、`limit`（默认 100；最大 1000）等筛选条件。
* 响应：`total`、`page`、`limit`、`hasMore`、`rows[]`（字段格式与 `GET /fapi/v3/income` 相同）。
* 时间跨度不受限制；`page` × `limit` ≤ 100,000。不传 `startTime` 和 `endTime` 时默认返回最近 7 天数据。
* 需传 V3 鉴权参数：`nonce`、`signer`、`signature`。

## 2026-10-21

### Futures V3 & Testnet — 改单后队列优先级重置

* `PUT /fapi/v3/order` 和 `PUT /fapi/v3/batchOrders`：改单成功后，订单时间优先级重置，重新排至同价位队列末尾。该规则对仅调整数量、不调整价格的改单同样适用。

### Futures V3 & Testnet — 策略订单新增 BBO peg 支持

* `POST /fapi/v3/placeStrategyOrder`：新增子订单字段 `pegPriceType`（`COUNTERPARTY_1/_3/_5/_10/_20` 或 `QUEUE_1/_3/_5/_10/_20`），适用于 `LIMIT`、`STOP`、`TAKE_PROFIT` 类型的腿。设置 `pegPriceType` 时 `price` 必须传 `"0"`。
* 新增警告说明：当入场腿使用 `pegPriceType` 时，止盈/止损腿的合理性校验通过响应体的 `failureCode: -4142` 返回，而非 HTTP 状态码。
* `GET /fapi/v3/openStrategyOrder`：新增说明，BBO 腿返回 `"price": "0"` 和 `pegPriceType` 字段。
* 更新 `POST /fapi/v3/order` 的 `pegPriceType` 描述：`LIMIT` 订单在下单时解析价格，`STOP`/`TAKE_PROFIT` 订单在触发时解析（原文档误写为"触发时"统一处理）。
* 移除 `POST /fapi/v3/order` 的 `pegOffset` 参数（现由撮合引擎自动解析）。
* 新增错误码：`-5035 INVALID_PEG_PRICE`（BBO peg 订单的 price 必须传 0）和 `-5036 PEG_PRICE_NOT_SUPPORTED`（该订单类型不支持 BBO peg）。

## 2026-10-19

### Futures V3 — 查询被邀请人信息

* 新增 `GET /fapi/v3/referral/inviteeInfo`（USER_DATA，权重 1）：查询某钱包地址是否通过调用者的邀请加入。
* 参数：`address`（EVM 或 Solana 钱包地址）。
* `isInvitee: true` 时响应：`walletAddress`、`dateJoined`、`feePaid`、`yourRewards`、`expiredStatus`。
* `isInvitee: false` 时只返回 `walletAddress`。
* 邀请关系 365 天内有效，已过期仍返回 `isInvitee: true`，同时 `expiredStatus: true`。
